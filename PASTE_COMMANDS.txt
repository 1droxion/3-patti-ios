# 3 Patti Social V1.8.2 — Build 22

Upload this ZIP into the root of your existing repo and run:

cd /workspaces/3-patti-ios
unzip -o three_patti_v182_repeat_iap.zip
rm three_patti_v182_repeat_iap.zip
flutter pub get
git add .
git commit -m "V1.8.2 repeat Apple IAP chip purchases"
git push

Then run Codemagic Build 22 and install it from TestFlight.

IMPORTANT: The app code can allow repeated consumable purchases, but Apple will not return a product until the exact product ID is fully configured in App Store Connect.
